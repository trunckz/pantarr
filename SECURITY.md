# Security policy

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately on GitHub:
[Security → Report a vulnerability](https://github.com/trunckz/pantarr/security/advisories/new), with the affected
version (or commit), the steps to reproduce and the impact you see. You will get an answer within
5 working days; a fix is prepared privately and published with a note once it is deployed. Reporters are credited
if they wish.

## Supported versions

Only the latest version of the `main` branch (and the hosted service) receives security fixes.

## Scope

In scope: the API, the web application, the browser extension and the userscripts, the hosted service.
Out of scope: denial of service by volume, reports from automated scanners without a demonstrated impact, the sites
of the stores themselves.
