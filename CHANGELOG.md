# Changelog

Notable changes, newest first. Versions follow [semantic versioning](https://semver.org/) from the first public release.

## Unreleased

- Browser extension 1.4.0, ready for the Chrome Web Store and Firefox Add-ons (`npm run extension:pack`,
  docs/extension/stores.md): no default instance (the address of your Pantarr is typed once, shown next to the code in
  Pantarr), no access asked beyond the store and recipe sites, icons at every size, Firefox data consent declared.

First public version: meal planning by an LLM, one shopping list (Mealie) split between store and online, purchases
and pantry learnt from receipts, browser extension for drive baskets (Intermarché, Leclerc, Carrefour, Auchan, U,
Chronodrive, Monoprix, Lidl Plus), calendars and shared lists, households and SSO, hosted mode. Bug reports and
feature requests from the app (user menu).
